This is a template post. The date comes from the filename, so name new posts
`YYYY-MM-DD-short-title.md` and give them a `title` and a `topic`.

Write in plain Markdown: **bold**, *italic*, [links](https://gohugo.io/), lists,
quotes and code.

```python
def greet(name: str) -> str:
    # Say hello
    return f"Hello, {name}!"
```

> To add photos to a post, make a folder named like the post (for example
> `2026-10-10-example-post/`), put the text in `index.md` and the photos beside it.
